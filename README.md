# Fanex.NAP.CTS.BIAlertService

BI Alert Service for Fanex NAP CTS Platform

## Project Structure

- **src/Fanex.NAP.CTS.BIAlertService** - Core business logic and features
- **src/Fanex.NAP.CTS.BIAlertService.JobService** - Web API and job scheduling service
- **test/Fanex.NAP.CTS.BIAlertService.Test** - Unit tests

## Prerequisites

- .NET 8.0 SDK
- Visual Studio 2019 or later / Visual Studio Code

## Getting Started

1. Open `Fanex.NAP.CTS.BIAlertService.sln` in Visual Studio
2. Restore NuGet packages
3. Build the solution
4. Run the JobService project

## Configuration

Configuration files are located in `src/Fanex.NAP.CTS.BIAlertService.JobService/`:
- `appsettings.json` - Base configuration
- `appsettings.LOCAL.json` - Local environment
- `appsettings.Development.json` - Development environment
- `appsettings.Production.json` - Production environment
